# Как забронировать аудиторию

Для знакомства с API откройте спецификацию в Swagger Editor. Для вызовов из терминала нужен Node.js с npm. Из корня ветки запустите `npx --yes @stoplight/prism-cli mock openapi.yaml`. Оставьте терминал открытым. Во втором терминале задайте `base=http://localhost:4010`. Учебный mock выдаёт примеры по контракту, состояние между запросами не сохраняет.

## От поиска до подтверждения

1. Выполните `curl "$base/rooms"`. Поле roomId — обозначение помещения, capacity — число мест. В примерах Б-214 вмещает 24 человека.
2. Проверьте время. Время ниже указано по UTC. Кодирование в пути соответствует Б-214.

```sh
curl -G "$base/rooms/%D0%91-214/availability" \
  --data-urlencode 'start=2026-10-01T09:00:00Z' \
  --data-urlencode 'end=2026-10-01T10:30:00Z'
```

3. Если available равно true, запросите бронь. Между проверкой и подтверждением комнату может занять другой диспетчер.

```sh
curl -i "$base/bookings" -H 'Content-Type: application/json' \
  -d '{"roomId":"Б-214","start":"2026-10-01T09:00:00Z","end":"2026-10-01T10:30:00Z"}'
```

4. Код 201 подтверждает создание. Сохраните id из ответа. Для примера с номером 42 запрос `curl "$base/bookings/42"` показывает аудиторию и время.

## Отмена и ошибки

Для отмены выполните `curl -i -X DELETE "$base/bookings/42"`, подставив свой номер. Код 204 означает успешную отмену. Тело ответа пустое. По контракту последующий поиск отменённой записи возвращает 404.

| Код | Что проверить |
|---|---|
| 404 | Сверьте номер подтверждения или обозначение помещения с каталогом. Возможно, бронь уже отменена |
| 409 | Обновите доступность и выберите другое время либо аудиторию |
| 422 | Укажите часовой пояс и убедитесь, что конец позже начала |
