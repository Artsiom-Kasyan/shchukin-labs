# Проверка границ бронирования

| Пример | Ожидание | Объяснение |
|---|---|---|
| [540, 630), [630, 720) | Нет конфликта | В минуту 630 первая пара уже закончилась |
| [540, 631), [630, 720) | Конфликт | Общая минута 630 |
| [540, 720), [600, 660) | Конфликт | Весь второй интервал занят |
| [0, 0), [0, 60) | Ошибка ввода | Бронь нулевой длительности недопустима |

При проверке первой версии упал test_touching_boundaries. Общее время существует, если начало каждого слота строго раньше конца другого. Замена двух сравнений на строгие устраняет ошибку при обоих порядках передачи аргументов. После правки прошли шесть тестов. Исключение для некорректных интервалов сохранено: ответ False позволил бы вызывающему коду принять сломанную бронь за свободное время.

Проверяемая область ограничена одним днём. Начало 0 и конец 1440 допустимы. Поддержка нескольких дат потребовала бы другого входного формата.
