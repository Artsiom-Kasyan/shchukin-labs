# Ревью функции overlaps

## 1. Какую минуту занимают обе пары?

Для пары 09:00–10:30 первая занятая минута имеет номер 540, последняя — 629. Следующая пара начинается с минуты 630. Множества минут не пересекаются. Если первое занятие заканчивается в 10:31, минута 630 принадлежит обоим слотам.

Ручная оценка студента для исходного примера: «Нет, нет общей занятой минуты, так как там до 10:30 не включительно, вторая с 10:30 включительно». Она согласуется с тестом на касание в обоих порядках.

В черновике равенство end_a и start_b удовлетворяло второму условию. Чтобы получить конфликт, начало каждой брони должно строго предшествовать концу другой. Поэтому исправлены **оба** сравнения. Смена только одного знака оставила бы ошибку при перестановке броней.

## 2. Достаточно ли примеров?

Пара тестов с одинаковым результатом может скрывать ошибку. Поэтому рядом с примером касания сохранён тест, в котором продление всего на минуту меняет ожидаемый ответ на True. Вложение проверяется в обе стороны, а полное совпадение — отдельным тестом.

Для дополнительной проверки использован независимый расчёт. На отрезке от 0 до 5 минут существует 15 непустых слотов с целыми границами. Для каждой из 225 пар тест строит множество минут первой брони и пересекает его с минутами второй. Непустое пересечение должно совпасть с ответом функции. Такой перебор удобен в тесте. В рабочей функции достаточно двух сравнений, поэтому её время и память постоянны.

## 3. Что пропустил первый зелёный прогон?

Документация обещала целые минуты. Python допускает сравнения с дробными числами, а True при числовом сравнении ведёт себя как 1. Примеры overlaps(0.5, 2, 1, 3) и overlaps(True, 2, 1, 3) проходили сквозь проверку диапазона. Исправление принимает ровно встроенный int. Несоответствие типа даёт TypeError, пустой или выходящий за сутки интервал — ValueError. Значение 1440 допустимо как конец последнего слота суток.

Предложения расширить модель датами, часовыми поясами или базой данных для этого варианта излишни. Тесты и вывод относятся к одной аудитории в одни сутки. Модуль не работает с файлами расписания и не принимает учётные данные.
