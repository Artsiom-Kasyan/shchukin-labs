# Лабораторная № 9 · Конфликт брони аудиторий

**Студент:** Касьян А.С.  
**Вариант:** 12

## Постановка

> Пересечение интервалов времени. Тесты: касание границ, полное пересечение, без пересечения. AI-review: off-by-one в границах.

Две заявки относятся к одной аудитории и одним суткам. Время задаётся целыми минутами от полуночи. Слот включает минуту начала и освобождает аудиторию в момент окончания. Поэтому 09:00–10:30 и 10:30–12:00 можно поставить подряд. Если продлить первую бронь до 10:31, обе заявки займут минуту с 10:30 до 10:31.

## Запуск и тесты

Из каталога проекта на Python 3 выполните:

```sh
git switch lab-09
python3 booking.py
python3 -m unittest discover -s tests -v
```

Демо выводит `Конфликт двух соседних пар: False`. Восемь тестовых методов завершаются с `OK`. Используются только средства стандартной библиотеки.

| Входные слоты в минутах | Результат | Причина |
|---|---|---|
| [540, 630), [630, 720) | False | Конец первого совпал с началом второго |
| [540, 631), [630, 720) | True | Общая минута 630 |
| [540, 720), [600, 660) | True | Второй слот целиком внутри первого |
| [0, 1440), [0, 1440) | True | Совпадают все занятые минуты |
| [540, 600), [630, 720) | False | Между бронями свободны 30 минут |
| [540, 540), [630, 720) | ValueError | Первая бронь имеет нулевую длительность |

## Работа с ИИ

**Инструменты и роли.** OpenAI Codex подготовил Python-функцию, тесты на unittest и разбор ошибок. Студент отдельно проверил смысл границ по примеру расписания. Команды запуска, вывод тестов и изменения кода позволяют повторить проверку без доступа к переписке.

**Пять ключевых промптов.** Ниже приведены сокращённые постановки этапов работы. В [журнале итераций](docs/prompts.md) указано, чем закончилась каждая проверка.

1. Реализуй на Python проверку конфликта двух броней одной аудитории в течение дня. Вход — четыре целые минуты, выход — логическое значение.
2. Напиши юнит-тесты на касание, полное вложение, равные интервалы, частичное пересечение и разрыв. Проверь неверные границы.
3. Проведи ревью на ошибку в одну минуту. Разбери случай 09:00–10:30 и 10:30–12:00, исправь сравнение и повтори тесты.
4. Проверь реализацию независимым способом: перечисли занятые минуты каждого слота на коротком отрезке и сравни результат с функцией.
5. Проверь обещание «целые минуты» на дробном числе, строке и логическом значении. Сначала зафиксируй тест, затем устрани расхождение.

**Что получилось у ИИ.** Функция проверяет два интервала без перебора каждой минуты. Тест на вложение полезен тем, что внутри большой брони могут находиться обе границы малой. Отдельная проверка с перестановкой аргументов показывает, что ответ не зависит от порядка заявок.

**Где ИИ ошибся.** В черновике оба сравнения допускали равенство. Для соседних пар функция возвращала True. Тест с разрывом в полчаса при этом проходил: обнаружить ошибку позволил именно пример с общей границей. После первой правки шесть тестов проходили, но функция всё ещё принимала 0.5 и True в качестве минут. Аннотация int сама по себе в Python ввод не проверяет.

**Ручная оценка и внесённые правки.** На вопрос об общей минуте студент ответил: «Нет, нет общей занятой минуты, так как там до 10:30 не включительно, вторая с 10:30 включительно». Это задаёт ожидаемый ответ независимо от кода. В реализации Codex изменил оба знака `<=` на `<`, затем добавил явную проверку целочисленных границ. Проверку предметного правила выполнил студент; изменения файлов и прогоны тестов выполнил Codex.

**Риски и принятые решения.**

| Риск | Как он проявляется в этой задаче | Как проверена или ограничена работа |
|---|---|---|
| Утечка данных | Для отладки можно по ошибке передать расписание с фамилиями, заявки или токен доступа | Для постановки и тестов достаточно четырёх вымышленных чисел. Демо не подключается к университетским системам |
| Лицензии | Предложенный моделью фрагмент может происходить из чужого проекта с условиями использования | Решение сводится к двум проверяемым неравенствам. Сторонние фрагменты и пакеты в проект не включены |

| Уверенный неверный ответ | Формула с двумя знаками равенства выглядит естественно, хотя блокирует соседние пары | Ожидание сформулировано по расписанию. Дополнительно реализация сверена с занятыми минутами для 225 упорядоченных пар слотов |
