# Лабораторная 8 · Бронирование аудиторий вуза

**Касьян А.С. · Вариант 12**

## Постановка

Бронь помещения на слот. User: найти аудиторию, забронировать, отменить. Tech: конфликты по времени. OpenAPI: аудитории, доступность, создать/отменить бронь.

## Как пользоваться документацией

[Инструкция диспетчера](docs/user.md) ведёт от поиска аудитории до отмены. [Техническое описание](docs/tech.md) объясняет контракт, правила времени и проверку целостности.

Откройте [openapi.yaml](openapi.yaml) в Swagger Editor через **File → Import file**. Пять операций описывают каталог помещений, доступность слота и жизненный цикл брони. Для локального просмотра примеров ответов можно запустить mock-сервер по инструкции диспетчера.
