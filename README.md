# Лабораторная 9 · Конфликт брони аудиторий

**Касьян А.С. · Вариант 12**

## Постановка

Пересечение интервалов времени. Тесты: касание границ, полное пересечение, без пересечения. AI-review: off-by-one в границах.

## Запуск

`python3 booking.py` выводит результат для двух соседних пар. `python3 -m unittest discover -s tests -v` запускает проверки без внешних зависимостей. Вход — четыре целых числа в минутах от полуночи, слоты относятся к одной аудитории и одним суткам.

## Работа с ИИ

Использован OpenAI Codex. Задачи для модели приведены в сокращённой воспроизводимой форме:

1. Напиши функцию проверки пересечения двух интервалов брони.
2. Подбери тесты на касание, вложение, совпадение и отсутствие пересечения.
3. Проверь знаки сравнения для соседних пар и прогони тесты после исправления.

Модель подготовила короткую функцию и симметричные примеры. Черновик ошибочно считал касание конфликтом. После запуска тестов Codex исправил оба сравнения. [Разбор с контрпримером](docs/ai-review.md). Ручная проверка студентом и его собственная оценка пока не внесены.

В тестах используются только условные интервалы. Передача реальных расписаний и учётных данных раскрыла бы лишние сведения. При заимствовании стороннего кода следует проверить лицензию. Даже правдоподобную формулу и предложенные моделью вызовы библиотек нужно проверять исполняемым примером.
