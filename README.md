# Лабораторная 1 · Парковка

**Касьян А.С. · Вариант 12**

## Постановка

Места с номерами; машина — номерной знак. Операции: занять свободное место, освободить место, найти место по номеру машины, число свободных мест.

## Запуск

Требуется Python 3.10 или новее. Запустите `python3 structural.py` и `python3 oop.py`. Оба примера занимают места 1 и 3, находят вторую машину на месте 3 и показывают одно свободное место. После выезда первой машины свободны два места.

В структурной версии функции получают словарь мест явно. В объектной версии парковка отвечает за уникальность номера машины, а отдельное место управляет въездом и выездом.
